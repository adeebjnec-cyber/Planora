Microsoft Project is still needed for saving .mpp files, running existing VBA macros and Microsoft's cloud services.

Which one to choose

Choose Planora if you…Choose Microsoft Project if you…
  • need professional scheduling without paying for a licence
  • receive .mpp files and need to open, analyse and report them
  • work with Primavera P6 users
  • work offline or without Microsoft 365
  • must send editable .mpp files to others
  • depend on existing VBA macros or Office add-ins
  • use Project Online, SharePoint or Teams for team updates
  • need portfolio management across many projects
