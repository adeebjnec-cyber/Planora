How the estimate is built

  1. Each task's work = duration × working hours per day × resource units (one person full time on a 10-day task = 80 hours).
  2. Each assignment's cost = work hours × the resource's standard rate (for example Project Manager at ₹1,500/h).
  3. Task cost = sum of its assignments + any fixed cost; phase cost = sum of its tasks; project cost = sum of all phases.

Limits of this estimate

  • It covers the labour and supervision recorded in the file only. Materials, equipment, crews (RCC Crew, Masonry Crew, Finishing Crew, Facade Contractor), overheads, taxes and contingency are not in the file. A full hospital budget would add these as material/cost resources or fixed costs in Planora.
  • Rates are the standard rates in the file; no overtime or rate changes are applied.
