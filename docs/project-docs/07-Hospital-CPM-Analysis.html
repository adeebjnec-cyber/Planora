The Critical Path Method finds the longest chain of dependent tasks. That chain sets the project duration: any delay to a task on it delays the whole project. Planora calculated this analysis automatically.

How the calculation works

  1. Forward pass. Starting at the project start, each task's Early Start (ES) is the latest Early Finish of its predecessors; Early Finish (EF) = ES + duration (working time on the calendar).
  2. Backward pass. Starting at the project finish, each task's Late Finish (LF) is the earliest Late Start of its successors; Late Start (LS) = LF − duration.
  3. Total float (slack) = LS − ES. It is how long a task can slip without delaying the project.
  4. Critical path = the tasks with zero total float.

The critical path

Every phase has zero float: the hospital plan is one continuous chain from Site Survey & Soil Investigation to Project Handover, with 75 critical tasks. Phases follow one another as:

Pre-Construction → Site & Earthwork → Foundation → RCC Structure → Masonry → MEP First Fix → Plaster & Waterproofing → Doors Windows & Facade → Flooring & Finishes → MEP Second Fix → External Development → Testing Commissioning & Handover → Project Handover

Only these milestones can slip; they are not linked to anything that follows them. Everything else is critical.

What this means for the project manager

  • Because the whole plan is critical, any delay in any task moves the handover date. The plan has no buffer.
  • To finish earlier, overlap phases (for example start MEP First Fix on lower floors while upper floors are still being built) or add crews to the longest phases: RCC Structure and Flooring & Finishes.
  • Track the critical tasks weekly; Planora shows them in red when the Critical path switch is on.
