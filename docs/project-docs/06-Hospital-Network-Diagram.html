A network diagram (activity-on-node) draws each activity as a box and each dependency as an arrow. The hospital plan is a single chain: each phase starts when the previous one is done, so every phase lies on the critical path (red).

Phase-level network

Activity-level network: Foundation phase

The same diagram at task level for one phase. Arrows are labelled with the link type (FS = finish-to-start, SS = start-to-start, SF = start-to-finish) and any lag.

All boxes come from Planora's calculated schedule. Planora's own Network Diagram view shows every one of the 91 tasks this way on screen.

Source. Hospital_Construction_Advanced.xml from the construction test pack, opened in Planora 1.1.0. Dates are the as-planned schedule (progress recorded in the file cleared), calculated by Planora on the file's calendar (Mon–Fri, 8:00–17:00). Two links in the file could not be imported (one to the project summary row, one to a missing task); Planora reports them as import notes. Amounts are in the file's currency units, shown as ₹.
