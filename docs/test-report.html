Summary

Result: all tests pass

Planora 1.1.0 passed every test in five levels of testing. Testing found 17 real bugs during development; all were fixed before release. One slow spot remains (Spelling on very note-heavy plans) and a few areas have not been tested yet (page 7).

A watchdog closed each dialog a command opened and recorded any error message. Run on 9 October 2026, 436 seconds.

Open items

Known limitations and what is not tested yet

Known limitations

ItemDetail
Spelling on note-heavy plansAbout 8–13 s on a plan with 34 long notes (instant on normal plans); a wait cursor is shown.
Dragging past the chart edgeThe chart does not scroll by itself while dragging a bar beyond its edge (Microsoft Project does).
Saving .mpp filesNot possible (closed format); Planora saves Microsoft Project XML instead.
Microsoft Project VBA macrosNot supported; Planora has its own macro language.
Installer not code-signedWindows shows a “Windows protected your PC” warning the first time.

Not tested yet

  • Printing to a real printer (print preview and PDF export were tested).
  • A full install and uninstall through Windows “Installed apps” on a clean PC (the installer self-test passed).
  • Opening Planora's exported XML in Microsoft Project itself.
  • Resource leveling results compared with Microsoft Project's leveling on the same files.
  • Use by real people over a longer period.
