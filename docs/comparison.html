Summary

The short answer

For planning, scheduling, tracking and reporting projects on a Windows PC, Planora does almost everything the desktop edition of Microsoft Project does, calculates the same dates, and opens Microsoft Project files — at no cost. Microsoft Project remains the choice when you need to save .mpp files, run existing VBA macros, or work inside Microsoft's cloud and Office ecosystem (Project Online, Project Server, SharePoint, Teams, Power BI).

Accuracy

Scheduling accuracy on real Microsoft Project files

A scheduler is only as good as its dates. Planora was tested on three plans saved by Microsoft Project itself.

For each file, the dates Microsoft Project had stored were read from the .mpp; then Planora rescheduled the plan from scratch with its own engine and the two sets of dates were compared, task by task. This test runs automatically with every change to Planora.

FileTasksStart and finish dates identical
Advanced Analytics Microsoft Project Plan3434 / 34
Commercial construction sample144144 / 144

Total188188 / 188

“Identical” means within one minute: Microsoft Project stores seconds, Planora schedules in whole minutes. The plans include fixed-duration tasks, milestones with resources, interrupted (stop/resume) tasks, delayed assignments, cost and material resources and contoured work. One task shows a displayed duration of 181.8 hours where Microsoft Project shows 180 hours, with the same dates.

Conclusion

What Planora does not do

  • Save .mpp files. Planora opens them, but saves .planora and Microsoft Project XML. Microsoft Project opens the XML and can save it as .mpp.
  • Run Microsoft Project VBA macros, COM automation or Office add-ins. Planora's own macro language covers common automation.
  • Connect to Microsoft's cloud: Project Online, Project Server, SharePoint, Teams, Power BI, timesheets and portfolio management.
  • Visual Reports to Excel or Visio, and Copy Picture to Office.
  • Run on Mac, Linux or the web. Planora is a Windows desktop program.

Two areas have not yet been cross-checked against Microsoft Project: resource leveling results on the same files, and opening Planora's XML in Microsoft Project. Both are implemented and tested in Planora itself.

Which should you choose?

Choose Planora if you…Choose Microsoft Project if you…
  • plan and control projects on Windows PCs and want desktop Microsoft Project's scheduling at no cost
  • receive .mpp files and need to open, analyse and report them
  • exchange schedules with Primavera P6 users
  • work offline or without Microsoft 365 accounts
  • want a modern interface with command search
  • must send editable .mpp files to clients or head office
  • depend on existing VBA macros or Office add-ins
  • use Project Online, Project Server, SharePoint or Teams for team updates and timesheets
  • need portfolio-level management across many projects
